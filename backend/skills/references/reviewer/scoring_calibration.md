# ReviewerAgent 评分校准参考

> 基于 CUMCM 获奖论文特征和评审经验
> 用于校准 ReviewerAgent 的 5 维评分标准

## 一、各维度评分锚点

### 数据支撑 (data_support)

| 分数 | 标准 | 典型表现 |
|:--|------|---------|
| 8-10 | 优秀 | 每个结论有具体数值+置信区间+样本量；图表有100+字分析 |
| 6-7 | 良好 | 大部分结论有数据，个别用模糊词；图表分析60-100字 |
| 4-5 | 合格 | 只有p值无效向量；图表引用但无分析；关键指标缺失 |
| 1-3 | 较差 | 结论空洞("效果较好")；无具体数值；图表无编号 |

### 建模逻辑 (modeling_logic)

| 分数 | 标准 | 典型表现 |
|:--|------|---------|
| 8-10 | 优秀 | 每个方法有"三要素理由"；假设验证充分；备选对比实质 |
| 6-7 | 良好 | 理由基本充分但细节缺失；个别假设未验证 |
| 4-5 | 合格 | 方法选择有简要理由但缺乏对比；假设合理性论证不足 |
| 1-3 | 较差 | 方法选择无理由可循；前后矛盾；假设脱离实际 |

### 可视化 (visualization)

| 分数 | 标准 | 典型表现 |
|:--|------|---------|
| 8-10 | 优秀 | 图表类型恰当；配色规范；图注完整(编号+标题+必要统计) |
| 6-7 | 良好 | 图表可用但细节改进空间(标签不全/配色一般/图注简略) |
| 4-5 | 合格 | 有图但数量不足或类型不当；缺图注或编号混乱 |
| 1-3 | 较差 | 缺核心可视化；图表无法支撑分析；编号格式错误 |

### 去AI味 (de_ai_effect)

| 分数 | 标准 | 典型表现 |
|:--|------|---------|
| 8-10 | 优秀 | 无禁用词句；语言自然流畅；"本文"统一；结论不套路 |
| 6-7 | 良好 | 个别禁用词但总体自然；部分段落模板化 |
| 4-5 | 合格 | 多处AI高频词；使用"我们"；句式单一；结论套话 |
| 1-3 | 较差 | 全文模板化；大量禁用词；明显机器痕迹 |

### 完整性 (completeness)

| 分数 | 标准 | 典型表现 |
|:--|------|---------|
| 8-10 | 优秀 | 全部必要章节齐全；摘要含完整四要素；参考文献≥5篇 |
| 6-7 | 良好 | 章节基本齐全但个别内容单薄(如敏感性分析简略) |
| 4-5 | 合格 | 缺少1-2个必要章节；摘要不完整(缺具体结果) |
| 1-3 | 较差 | 缺失多个核心章节；无参考文献或格式全错 |

## 二、常见扣分项权重

| 扣分项 | 严重度 | 扣分 | 说明 |
|-------|:--:|:--:|------|
| 结论无数据支撑 | 🔴 | -2 | "效果较好"、"显著提升"等 |
| 仅有p值无效向量/CIs | 🟡 | -1 | 统计报告不完整 |
| 使用"我们"代替"本文" | 🟡 | -0.5 | 每出现3次 |
| 摘要缺失具体数值 | 🔴 | -2 | 必须含至少3个数值 |
| 图表无分析 | 🟡 | -1 | 每张缺分析的图 |
| 4框完整border的图 | 🟢 | -0.5 | 图表垃圾 |
| 红绿配色(色盲不友好) | 🟢 | -0.5 | 应该用蓝橙 |
| 表格用Markdown管道表 | 🔴 | -1 | 应该用HTML table |
| 参考文献格式错误 | 🟡 | -1 | GB/T 7714 |

## 三、阈值设定

- `passed` = overall_score >= 6.0 且所有维度 >= 4
- `reviewer_feedback_rewrite` = overall_score < 6.0（触发 Writer 重写）
