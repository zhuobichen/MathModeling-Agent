# 数学建模竞赛论文写作模式参考

> 提取自 CUMCM 历年获奖论文（2010-2024，已排除 2022C 测试数据）
> 供 WriterAgent 生成论文时参考结构和写作风格

## 一、论文结构标准

获奖论文通用结构（强制顺序）：

```
# 摘要（一页以内）
# 一、问题重述
# 二、问题分析
# 三、模型假设
# 四、符号说明与数据预处理
# 五、模型的建立与求解
  ## 5.1 问题一
  ## 5.2 问题二
  ...
# 六、敏感性分析
# 七、模型评价与改进
# 参考文献
# 附录（可选）
```

## 二、摘要写作模式（高频句式）

获奖论文摘要结构（问题→方法→结果→结论，4-5句）：

```
句1（问题）: 本文针对[问题背景]，研究[核心目标]。
句2（方法）: 基于[数据特征]，构建了[方法名称]模型，通过[验证方式]评估模型性能。
句3-4（结果）: 结果表明，[具体数值结果]。
句5（结论）: 本文所建模型为[应用场景]提供了[价值描述]。
```

**关键要求**：
- 摘要必须包含至少3个具体数值（准确率、R²、误差等）
- 不出现"本文首先...其次...最后"的流水账句式
- 关键词 3-5 个，用分号分隔

## 三、问题分析写作模式

对每个子问题的分析包含：
1. **问题本质判断**：一句话概括"问题X本质上是[建模类型]问题"
2. **关键难点**：该问题的核心挑战是什么（数据限制、约束条件、精度要求等）
3. **方法选择理由**：为什么选此方法（与数据特征的匹配度）

**避免**：
- 直接复述题目原文
- 空洞的"需要建立数学模型来解决"
- "首先...其次...最后"的枚举式写法

## 四、模型假设写作规范

每条假设包含三要素：
- 假设内容：用粗体标注（如**数据完整性假设**）
- 合理依据：为什么可以做这个假设
- 影响评估：违反假设对模型的后果

**反例**（太弱）：
```
假设1：假设数据真实可靠。
```

**正例**（充分）：
```
（1）**数据有效性假设**：假设题目提供的销售数据源于真实交易记录。
依据：数据包含具体日期和商品编号，与超市实际运营场景相符。
若此假设不成立，后续所有统计推断的结论将失去事实基础。
```

## 五、方法选择理由模式

每个子问题的方法选择必须包含"三要素"：

1. **数据特征论证**："该数据具有[特征]，因此适用于[方法]"
2. **备选方法对比**："相比[备选A]和[备选B]，[选中方法]更适合因为..."
3. **前提条件验证**："[选中方法]的适用前提[条件]在本数据中满足（检验结果：p=0.xx）"

**高频方法组合**（数据题）：
- 关联分析：卡方检验(分类) / Spearman相关(连续) / 对应分析(可视化)
- 聚类：GMM(软分配) / 层次聚类(可解释) / K-means(高效)
- 分类：XGBoost(高精度) / 逻辑回归(可解释) / 随机森林(鲁棒)
- 预测：随机森林回归 / ARIMA(时间序列) / 灰色预测(小样本)
- 评价：AHP+TOPSIS（主观+客观组合最受评委青睐）
- 验证：K折交叉验证 / Bootstrap / 留一法

## 六、结果呈现规范

每个结果必须包含：
- 具体数值（不泛化："准确率94.3%"而非"效果较好"）
- 置信区间或标准差
- 对比基准（如比基准模型提升X%）
- 图表交叉引用（"如图X所示"）

**图表数量**：
- 问题分析部分：0张（纯文字分析）
- 数据预处理：1-2张（分布图、缺失率图）
- 每个子问题：2-3张核心分析图
- 敏感性分析：1-2张
- 全文：8-15张

## 七、模型评价与改进规范

**优点**（3-4条）：
- 每条结合具体结果数据
- 不泛化："模型具有较高的准确率"→"模型在测试集上准确率达94.3%"
- 涉及方法选择、数据利用、模型验证三个维度

**缺点**（2-3条）：
- 诚实：承认真正存在的局限
- 具体：指出哪个假设可能过强、哪种数据缺失影响结果
- 不泛化："模型假设可能过强"→"假设2中忽略了季节性波动，导致Q2的预测偏差"

**改进**（2-3条）：
- 不能是"收集更多数据"这种套话
- 要针对具体缺点提出可操作方案
- 如"可将假设2扩展为分段线性函数以容纳季节性波动"

## 八、参考文献格式（GB/T 7714-2025）

```markdown
[1] 司守奎, 孙兆亮. 数学建模算法与应用[M]. 第3版. 北京: 国防工业出版社, 2021.
[2] Breiman L. Random forests[J]. Machine Learning, 2001, 45(1): 5-32.
```

至少引用 5 篇，包含建模方法原论文和统计分析教材。
