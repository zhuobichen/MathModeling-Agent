## 复现方式

```bash
cd backend
# 用框架重跑（需先删掉 project/work_dir/<task_id> 或换新任务号）
./.venv/Scripts/python.exe main.py run \
  --question "../测试_A题/A题.pdf" --data "../测试_A题" \
  --driver file --pipeline "../pipelines/competition_lite.toml"
```

`--driver file` 会把提示词落成 `_driver/*.request.md` 并暂停；写入同名
`.response.md` 后 `main.py resume <task_id> --driver file` 继续。可反复续跑。

## 已知局限

- **问题三浮子纵摇角与公开解答不吻合**（垂荡方向已高精度验证）。成因已定位为方程
  结构差异——本文采用纵摇与垂荡解耦的处理，而公开解答中纵摇转动惯量相差达 8 倍
  （4133 / 8175 / 25083 / 33000），说明其纵摇方程建立在不同参考点上并含耦合项。
  本文保留自洽的解耦处理，未为迎合某一来源的数值而调参。
- 问题三中振子到转轴距离 `r0 = 0.5 m` 为假设取值（取弹簧原长），题目未直接给出。
- 问题四的公开解答自身分歧达 3 倍以上（345 W / 1145 W），无公认基准可比。
- 浮子纵摇转动惯量按"质量均匀分布于壳体表面"积分求得（积分质量与给定值精确吻合），
  但该分布解释本身未获独立验证。
